# Android 0.2.2 sinov versiyasi

- Lotin → kirill klaviaturasida `t` va `s` ketma-ket bosilsa `тс` chiqadi, `ц` emas.
- Bosh harflar ham alohida saqlanadi: `TS → ТС`.
- Eski lotin → yangi lotin rejimida `ts` o‘zicha qoladi.

APK’ni telefonga yuklab oling, oching va ilovadagi ikki qadam bilan klaviaturani yoqing. Oldingi sinov APK boshqa debug kaliti bilan imzolangan bo‘lsa, avval uni o‘chirib, yangisini o‘rnating.

Bu hali sinov nusxasi. Telegram va boshqa ilovalarda haqiqiy telefonda alohida tekshirish kerak. Ilova internetga ulanmaydi.
