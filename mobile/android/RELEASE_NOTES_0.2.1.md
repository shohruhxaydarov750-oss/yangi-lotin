# Android 0.2.1 sinov versiyasi

- Shift/Caps Lock yoqilganini tugma rangi va belgisi ko‘rsatadi.
- Kursor o‘zgarganda o‘girilmagan kirill harfi chiqib qolishi tuzatildi.
- Asosiy oynadagi Qo‘yish tugmasi kursor belgilanmagan holatda ham ishlaydi.
- Backspace va Enter xabar maydoniga o‘xshash sinov oynasida tekshirildi.
- Windows va Androidda `щ → ş` qoidasi bir xil.

APK’ni telefonga yuklab oling, oching va ilovadagi ikki qadam bilan klaviaturani yoqing. Oldingi sinov APK boshqa debug kaliti bilan imzolangan bo‘lsa, avval uni o‘chirib, yangisini o‘rnating.

Bu hali sinov nusxasi. Telegram va boshqa ilovalarda haqiqiy telefonda alohida tekshirish kerak. Ilova internetga ulanmaydi.
